# DBMLFF Tutorial: Building Force Field for EC Molecule

## Overview
This tutorial provides a complete guide to building the Density-Based Machine Learning Force Field (DBMLFF) for EC (ethylene carbonate) molecules. The working directory is `example_EC/train`. The same workflow applies to building DBMLFF for other molecules. The DBMLFF framework consists of three key components: MLFF, DB, and POL, which collectively describe molecular interactions with high accuracy and computational efficiency.

## Prerequisites/Environment Configuration

### 1. Python Environment Setup
```bash
export PYTHONPATH=train/dataset:${PYTHONPATH}
```

### 2. MPI Package Compilation
MPI package is provided at `./example_EC/mpich-3.4.3`

**Working Directory:** `train/dataset/md_src`

```bash
# Load compilation environment
source env.sh

# Compile programs
make
```

### 3. Access PWmat for DFT Calculations
The current code is based on structure files and calculation outputs generated by PWmat.

## Step-by-Step Procedure

### 1. Parameter File Generation
**Working Directory:** `train/dataset/generate_file`

#### 1.1 Parameter Setup
Modify molecular-specific parameters in `aux_dbmlff.py`:

```python
# Example parameter settings
MolEindexList = [element_indices]
MolAtomSysList = [atomic_symmetry_info]  
atomicMassList = [atomic_masses]
zValenceList = [valence_electrons]
moveStartAtomId = [reference_atom_index]
```

#### 1.2 Structure Optimization
- Optimize target molecular structure in `reference_conf/`
- Save optimized structure as `atom_EC.config`

#### 1.3 Bond Parameterization
```bash
# Update molType in qsub scripts
sed -i 's/molType=.*/molType=EC/g' qsub_1.sh qsub_2.sh

# Execute parameter generation
bash qsub_1.sh

# Modify bond file and rerun
vim ./result/bond.molecule_EC_need_modify  # Add bond types and counts
mv ./result/bond.molecule_EC_need_modify ./result/bond.molecule_EC_bt
bash qsub_2.sh
```

**Output Location:** `train/dataset/generate_file/results`

### 2. DB Component: Monomer Charge Distribution Fitting
**Working Directory:** `train/DB` (Requires completion of Steps 3.1 and 3.2 first)

```bash
# Step 2.1: Configuration Selection
cd DB_dataset/
bash choose_conf.sh  # Randomly selects 50 EC configurations

# Step 2.2: DFT Charge Density Calculation  
cd ../DB/
bash qsub_1.sh

# Step 2.3: Charge Density Fitting
# Set z_valence in qsub_2.sh to total valence electrons of the molecule
bash qsub_2.sh
```
Fitted charge density results are located at `DB/2_fit_DB/rho2xsf/RHO.xsf`

# Step 2.4: Validation
Set n123 values in `DB/3_check/egg_box/template/run_mpich.sh`
```bash
bash qsub_3.sh  # Tests DB convergence
```
Visualization results are located at `DB/3_check/egg_box/sample/data_out`. The force and energy curves should converge to straight lines when n123 approaches the recommended value [7 times the box size (in Angstroms)].

**Quality Checks:**
- Check consistency between fitted charge density file `RHO.xsf` and DFT-calculated charge density file `DB/1_SCF/SCF/50/RHO.xsf` for the same EC molecule

### 3. MLFF Component: Linear Model for DFT-DB Differences
**Working Directory:** `train/MLFF`

#### 3.1 AIMD Data Preparation
**Multi-molecule System:**
- Build initial model with 15 EMC molecules at experimental density
- AIMD: 400K, 700K, 1200K (5000 steps, 0.5 fs, NVT ensemble)

**Monomer Simulations:**
- 3 random EC molecules
- Single-molecule AIMD: 400K, 600K, 1900K (5000 steps, 0.5 fs, NVT ensemble)

#### 3.2 Configuration Collection
```bash
cd MLFF_dataset/
# Configure parameters in get_conf.sh
vim get_conf.sh  # Set temperature points and sampling parameters
sbatch get_conf.sh  # Extracts single-molecule configurations from AIMD trajectories in step 3.1 and saves them to corresponding Conf_* folders, while flagging abnormal molecules. Molecules with bond lengths deviating more than 20% from the average will be excluded from subsequent training.
```

#### 3.3 SCF Calculations
```bash
cd ../1_SCF/

# SCF calculations
bash qsub_1.1_scf.sh

# Extract energies and forces  
bash qsub_1.2_get_dft_eng_force.sh

# Energy correction
bash qsub_2_energy_shift.sh
```

#### 3.4 DB Calculations and Model Fitting
```bash
# DB energies/forces calculation
cd ../2_dbmlff/
bash qsub.sh

# Model fitting
cd ../3_fit_mlff/
bash get_dataset.sh  # Prepares dataset
sbatch run.sh        # Fits MLFF model
```
Visualization results are located at `/MLFF/3_fit_mlff/fit_dir/eng_force_dataset.png`

**Quality Checks:**
Check the consistency between MLFF predictions and DFT references for energy and atomic forces in the visualization results at `eng_force_dataset.png`

### 4. POL Component: Polarization Model
**Working Directory:** `train/POL`

```bash
# Complete polarization workflow
bash qsub_0_1.sh    # Structure relaxation
bash qsub_2.sh      # Point charge generation
bash qsub_3.1.sh    # Task splitting
bash qsub_3.2.sh    # DFT calculations  
bash qsub_3.3.sh    # Result integration
bash qsub_4_5.sh    # Format conversion and fitting; visualization at POL/5_fit_direct_pxyz/plot_test.fit.png
bash qsub_6_7.sh    # Intramolecular polarization
```

**Quality Checks:**
Check the consistency between DBMLFF predictions and DFT references for polarization energy in the visualization results at `plot_test.fit.png`

## Molecular Dynamics Simulation using DBMLFF
**Working Directory:** `example_EC/MD`

```bash
bash qsub.sh  # Copies the potential functions trained above from train folder to form complete DBMLFF; results located at MD/template/mol.1
```

## Required Files for MD Simulation

### Force Field File
- `mol.1`: Automatically generated from previous steps

### Control File (`MD.input`)
```
...
2, 100, 0.5, 300, 300         ! iMD, MDsteps, dt, T1, T2
...
```

We provide a template at `MD/template/MD.input`. For different simulation needs, generally only the parameters in the second line need to be modified, as shown above: ensemble, MD steps, time step, initial temperature, final temperature.

### Structure File (`atom.config`)
```
Total_Atoms  Molecule_Types  Atoms_per_Molecule  Molecule_Counts
[lattice vectors...]
[atomic coordinates...]
```

### Supporting Files
- Pseudopotentials: `*.nc.pbe.UPF.ionrhoR` (provided, located at `MD/template`)
- Submission script: `run_mpich.sh` (provided, located at `MD/template`)

**Note:** The script uses software libraries and tools such as CUDA, NVHPC, MKL, NCCL, which are loaded via modules in the Longxun Supercomputing Cloud. Users can also deploy them locally as needed.
